OpenSlide brings tasks, focus, daily notes, and calendars into a compact Windows corner workspace.

### Install

- **OpenSlide-Setup-0.2.0.exe:** Windows 10/11 x64 installer with Start Menu and desktop shortcuts.
- **OpenSlide-Portable-0.2.0-x64.zip:** extract the entire folder and run OpenSlide.exe.
- **SHA256SUMS.txt:** checksums for both downloads.

### In this release

- OpenSlide, designed and maintained by Anagh.
- Refined navigation, task hover/active states, clearer focus controls, and Inter typography.
- Corner hover opening, optional top calendar drawer, pinning, and customizable appearance.
- Task management, countdown/stopwatch, daily notes, reminders, and 7/30-day focus insights.
- Optional read-only Google Calendar connection using your Desktop OAuth client.
- Nine animated companion choices with still and reduced-motion modes.
- An animated, reproducible README tutorial using real app captures and synthetic data.
- Windows CI build workflow, contribution guide, MIT license, and bundled font notices.

### Current limitations

The installer is unsigned. Reminders require the app to be running. Google Calendar needs your own Desktop OAuth JSON; Apple, Outlook, and Notion database imports are not included. Automated checks cover native window geometry, layouts, planner logic, and simulated calendar providers; live Google sign-in and physical mixed-DPI devices require account/device checks.

Press **Alt+N** to open the panel, or hover in the **bottom-right corner**. Choose **Customize** to make it yours.
