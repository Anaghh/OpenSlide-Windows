# Fonts

OpenSlide defaults to **Inter** and bundles the following unmodified font families:

| Family | License | License source |
| --- | --- | --- |
| Inter | SIL Open Font License 1.1 | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt) |
| DM Sans | SIL Open Font License 1.1 | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt) |
| Inconsolata | SIL Open Font License 1.1 | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/inconsolata/OFL.txt) |
| Roboto Condensed | SIL Open Font License 1.1 | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/robotocondensed/OFL.txt) |
| Metropolis | Unlicense | [Metropolis](https://github.com/dw5/Metropolis/blob/master/UNLICENSE) |

The license texts are included alongside the unmodified font binaries. Fonts retain their individual licenses.

**Avenir** remains a system-font choice for users who already have it installed; OpenSlide does not redistribute its font binaries. If it is unavailable, the app falls back to Inter. Existing font preferences continue to work.
